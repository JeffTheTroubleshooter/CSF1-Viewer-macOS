# CSF1 Viewer — macOS

Public host tool for [JCkernel](https://github.com/JeffTheTroubleshooter/JCkernel) CSF1 disks.

Sister editions:

- [CSF1-Viewer-Linux](https://github.com/JeffTheTroubleshooter/CSF1-Viewer-Linux)
- [CSF1-Viewer-Windows](https://github.com/JeffTheTroubleshooter/CSF1-Viewer-Windows)

## Run

```bash
chmod +x CSF1-Viewer.command CSF1-Viewer.sh
./CSF1-Viewer.command
```

Needs Python 3. **Update** reads this public repo. No GitHub login.
